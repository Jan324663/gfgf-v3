# gfgf.org V3

WordPress-Neuentwicklung fuer gfgf.org.

## Struktur

- `wp-content/themes/gfgf-v3/` - eigenes WordPress-Theme fuer V3
- `wp-content/plugins/gfgf-service-docs/` - erstes Projekt-Plugin fuer Schaltplaene / Unterlagen
- `config/` - nicht-geheime Konfigurationsvorlagen
- `scripts/` - lokale Setup- und Deployment-Hilfen
- `docs/` - technische Projektdokumentation
